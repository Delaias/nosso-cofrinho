# Nosso Cofrinho 2.0

Pacote 1: base visual em Next.js + TypeScript + Tailwind CSS. A branch `main` permanece com a versão HTML atual.

## Executar localmente

1. Instale Node.js 20 ou superior.
2. Rode `npm install`.
3. Rode `npm run dev`.
4. Acesse `http://localhost:3000`.

## Importante

Login, cadastro, convites, dados sincronizados e administrador ainda **não estão conectados**. As telas desta fase são demonstrativas. Jamais coloque chaves privadas ou senhas no código. Na próxima fase configuraremos Supabase Auth, banco PostgreSQL com RLS, confirmação de e-mail e convites.
