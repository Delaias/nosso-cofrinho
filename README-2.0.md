# Nosso Cofrinho 2.0
Pacote 1: projeto Next.js, TypeScript e Tailwind CSS, criado na branch cofrinho-2.0. A branch main não foi alterada.

## Executar
Instale Node.js 20+. Em um terminal, execute:
```
npm install
npm run dev
```
Abra http://localhost:3000.

## Status
Interface visual e navegação de demonstração. Cadastro, login, senhas, convites, admin e notificações reais ainda não foram implementados. Não informe senhas reais nos formulários.
